# Agence 2 - Sujet 1

## Votre première mission

créer un site web pour l'agence de développement web "Agence 2" (ou le nom de votre choix). Le site doit présenter les services de l'agence, les projets réalisés, l'équipe et les coordonnées. Le site doit être responsive et accessible. Le site utilisera obligatoirement un outil de Jamstack. Celui de votre choix, mais vous justifierai et présenterai votre choix. **Chaque agence utilise un outil différent.**

## Votre premier client

Le client est un responsable des outils de son IUT. Il souhaite moderniser un Intranet et répondre aux attentes des étudiants. Il a déjà une structure de base, vous devrez vous intégrer dans cette structure et proposer la partie étudiant. Les fonctionnalités sont libre, le client n'a pas d'idée pré-concues. Le client pourra vous communiquer plus tard une structure d'API. Le "template" de base est existant.
